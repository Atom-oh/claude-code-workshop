SETUP 01

Claude HUD, 세션 계기판

5분

상태줄에 토큰 사용량, 활성 에이전트, 투두, 깃 상태를 상시 표시하는 HUD 플러그인입니다. 캡스톤처럼 긴 빌드에서 컨텍스트가 얼마나 남았는지 감으로가 아니라 눈으로 봅니다. 원본: github.com/jarrodwatts/claude-hud

1설치와 설정, 순서대로 한 줄씩

Claude 세션 안에서 세 줄이면 끝납니다. 순서가 중요합니다: 마켓 등록 → 설치 → 상태줄 설정.

Claude 세션 입력 1/3
/plugin marketplace add jarrodwatts/claude-hud
Claude 세션 입력 2/3
/plugin install claude-hud

설치 범위를 묻는 화면이 뜨면 기본값 Install for you (user scope)에서 Enter를 누릅니다. ✓ Installed claude-hud. Plugin is now active.가 나오면 재시작 없이 바로 다음 줄로 갑니다.

Claude 세션 입력 3/3
/claude-hud:hud 상태줄을 설정해줘. 프리셋은 Full로

/claude-hud:hud 하나로 상태줄 설치, 미리보기, 표시 항목 변경, 문제 확인을 모두 합니다. Claude가 미리보기를 보여 준 뒤 설정을 적용하면 입력창 아래에 모델, 컨텍스트, 캐시, 도구 활동이 표시됩니다. 나중에 항목을 바꾸고 싶으면 같은 명령에 "에이전트 표시는 꺼줘"처럼 말로 요청합니다.

예전 안내의 /claude-hud:configure, /claude-hud:setup claude-hud 0.15부터 두 명령이 /claude-hud:hud 하나로 합쳐져, 예전 명령은 Unknown command로 나옵니다. 하단 바가 안 보이면 /exit로 나갔다가 claude로 재진입합니다.

출품 방법

라운드 마지막

출품은 캡스톤 개요의 출품 양식을 따릅니다. 양식, 마감, 쇼케이스 방식은 그 페이지가 기준입니다.

(선택) 만든 앱이나 웹 리포트를 다른 사람이 열 수 있는 주소로 공유하고 싶다면 Claude에게 CDK 배포를 맡길 수 있습니다. CloudFront 배포는 필수가 아닙니다. 맡길 때는 아래 세 표준 패턴 중 하나를 이름으로 적습니다. 정적 파일과 서버 앱 패턴, Lambda 함수 URL은 들어오는 길이 CloudFront 하나뿐이고, 버킷이나 로드 밸런서를 인터넷에 직접 열지 않습니다.

무엇을 올리나표준 패턴프롬프트에 적을 말
정적 파일 (HTML 리포트, 한 페이지 앱)S3(비공개) + CloudFront(OAC) + BucketDeployment"S3 버킷은 퍼블릭 접근을 모두 막고 CloudFront OAC로만 읽게"
서버 앱 (컨테이너)CloudFront VPC origin → 내부(internal) ALB → ECS Fargate"ALB는 internal로 만들고 CloudFront VPC origin으로만 연결. ALB 보안 그룹은 CloudFront origin-facing prefix list만 허용"
가벼운 API, 함수CloudFront → Lambda 함수 URL(OAC) 또는 API Gateway"Lambda 함수 URL은 AWS_IAM 인증, CloudFront OAC로 서명"

정적 파일의 예는 R2-1 04의 (선택) 공유 단계입니다. 서버 앱 패턴은 VPC origin을 만드는 데 최대 15분이 더 걸리고, VPC에 인터넷 게이트웨이가 붙어 있어야 합니다(트래픽이 그 길로 가지는 않습니다). POST 본문을 받는 API는 Lambda 함수 URL보다 API Gateway가 간단합니다. 함수 URL에 OAC를 쓰면 POST와 PUT 요청을 보내는 쪽이 본문의 해시를 헤더에 넣어야 하기 때문입니다. 다만 API Gateway는 기본 주소(execute-api)가 인터넷에 열려 있어, CloudFront만 거치게 하려면 기본 엔드포인트를 끄거나 비밀 헤더를 검사하는 등 따로 막아야 합니다. 쇼케이스가 끝나면 npx aws-cdk@2 destroy로 내립니다.
