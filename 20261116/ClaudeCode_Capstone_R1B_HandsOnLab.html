자기 agent 2개

25분

시세를 정리하는 agent와, 이상 거래 후보를 찾는 읽기 전용 검토 agent를 만듭니다. 두 agent 모두 도구를 MCP 도구와 읽기로 좁힙니다.

agent 정의는 Ch3의 방식 그대로 .claude/agents/ 아래 마크다운 파일입니다. MCP 도구는 mcp__<서버 이름>__<도구 이름> 형식으로 tools에 적습니다. 이 서버라면 mcp__seoul-realestate__search_trades입니다. tools를 적으면 그 밖의 도구(쓰기, Bash, 웹)는 쓸 수 없습니다. 아래 이름과 기준은 예시이고, 같은 틀 안에서 주제를 바꿔도 됩니다.

1시세 정리: price-summarizer
Terminal, 전체 복사
cd ~/claude-lab/capstone
cat > .claude/agents/price-summarizer.md << 'EOF'
---
name: price-summarizer
description: |
  서울 자치구 한 곳의 한 달 매매 실거래를 모아 시세를 정리하는 담당.
  사용 시점: "OO구 YYYYMM 시세 정리"처럼 지역과 기간이 정해진 시세 요약이 필요한 경우.
tools: mcp__seoul-realestate__search_trades, Read
model: sonnet
---
당신은 서울 부동산 시세를 정리하는 담당자입니다.

# 데이터
- seoul-realestate MCP의 search_trades(gu, year_month, limit)만 씁니다. 다른 호출은 하지 않습니다.
- THING_AMT는 만원, ARCH_AREA는 ㎡입니다. 취소일 RTRCN_DAY가 있는 행은 시세 계산에서 뺍니다.
- 건물명이 "샘플"로 시작하면 합성 데이터(mock)입니다. 결과 첫 줄에 mock인지 실호출인지 적습니다.

# 정리 순서
1. 요청의 자치구와 연월로 search_trades를 limit 100으로 부릅니다.
2. 건물용도(BLDG_USG)별 건수와 ㎡당 금액(THING_AMT / ARCH_AREA)의 중앙값, 최저, 최고를 구합니다.
3. 거래가 많은 법정동(STDG_NM)을 세 곳까지 적습니다.

# 출력 형식
- 표: 건물용도, 건수, ㎡당 중앙값(만원), 최저, 최고
- 한 줄 요약
- 본번과 부번(MNO, SNO), 건물명은 쓰지 않습니다. 법정동까지만 적습니다.
EOF

  사용 시점: 시세 정리 뒤, 또는 특정 자치구와 달의 거래 중 눈여겨볼 것을 고를 때.

model: sonnet

# 이상 거래 후보 기준
1. ㎡당 금액이 같은 묶음의 중앙값보다 50% 이상 낮다
2. ㎡당 금액이 같은 묶음의 중앙값의 2배 이상이다
3. 취소일(RTRCN_DAY)이 있다
4. 신고구분(DCLR_SE)이 직거래이면서 1번에도 해당한다

# 출력 형식
- 후보마다: 법정동, 건물용도, 계약일, 금액, ㎡당 금액, 중앙값 대비 비율, 해당 기준 번호
- 마지막 줄: PASS(후보 없음), WARN(1번에서 3번), FAIL(4번 해당)
- "이상 거래 후보"는 더 확인할 거래라는 뜻이지 위법 판단이 아닙니다. 그렇게 적습니다.
- 본번과 부번(MNO, SNO), 건물명은 쓰지 않습니다.
EOF

가드레일

25분

API 키가 파일, 명령, 커밋, 프롬프트에 들어가는 것을 막는 훅과, Claude의 호출 대상을 openapi.seoul.go.kr로 묶는 훅을 fail-closed로 등록합니다.

원리는 Ch2 Lab 2 가드레일과 DLP와 같습니다. 훅에서 exit 2가 차단이고, 오류 경로(jq 없음, 입력 해석 실패, grep 오류)에서도 exit 2를 내야 fail-closed입니다. 키는 05 단계에서 claude mcp add --env로 사용자 설정(~/.claude.json, 작업 폴더 밖)에만 넣습니다. 그래서 키 훅은 그 파일에서 등록된 키 값을 읽어 와 같은 값이 보이면 막고, 그 파일 자체를 열려는 요청도 막습니다.

1키 차단 훅: key-guard.sh
Terminal, 전체 복사
cd ~/claude-lab/capstone
cat > .claude/hooks/key-guard.sh << 'EOF'
#!/bin/bash
INPUT=$(cat)
command -v jq >/dev/null || { echo "KEY: 검사기 오류(jq 없음) - 안전을 위해 차단" >&2; exit 2; }
TEXT=$(printf '%s' "$INPUT" | jq -r '(.tool_input // {prompt: .prompt}) | [.. | strings] | join("\n")') \
  || { echo "KEY: 입력 해석 실패 - 차단" >&2; exit 2; }

# git 저장소에서 git commit 이면 커밋에 들어갈 내용(staged diff)도 함께 본다
if printf '%s' "$TEXT" | grep -Eq 'git[[:space:]].*commit' && git rev-parse --git-dir >/dev/null 2>&1; then
  DIFF=$(git diff --cached 2>/dev/null) || { echo "KEY: 커밋 내용 검사 실패 - 차단" >&2; exit 2; }
  TEXT="$TEXT
$DIFF"
fi

# 1) 등록된 키 값 그대로 (claude mcp add --env 로 ~/.claude.json 에 들어간 값)
KEYVAL=${SEOUL_API_KEY:-$(jq -r '[.. | objects | .SEOUL_API_KEY? | strings] | first // empty' "$HOME/.claude.json" 2>/dev/null)}
if [ ${#KEYVAL} -ge 8 ]; then
  printf '%s' "$TEXT" | grep -qF -- "$KEYVAL"; RC=$?
  [ "$RC" -eq 0 ] && { echo "KEY: 서울 API 키 값이 들어 있어 차단합니다" >&2; exit 2; }
  [ "$RC" -eq 1 ] || { echo "KEY: 검사기 오류(grep $RC) - 차단" >&2; exit 2; }
fi

# 2) 키를 값으로 적는 모양, URL 경로에 든 키, 키가 저장된 사용자 설정 파일, 프로세스 환경 변수 엿보기
PAT="SEOUL_API_KEY[\"' ]*[=:][\"' ]*[A-Za-z0-9]{8,}|openapi\.seoul\.go\.kr:8088/[A-Za-z0-9]{8,}/|\.claude\.json|/proc/[^[:space:]]*/environ|(^|[^A-Za-z0-9_])ps[[:space:]]+[A-Za-z]*e"
printf '%s' "$TEXT" | grep -Eq -- "$PAT"; RC=$?
[ "$RC" -eq 1 ] && exit 0      # 1 = 패턴 없음 → 통과
if [ "$RC" -eq 0 ]; then
  echo "KEY: 키를 파일, 명령, 커밋, 프롬프트에 적는 요청은 차단됩니다. 키는 MCP 등록(--env)으로만 넣습니다" >&2
else
  echo "KEY: 검사기 오류(grep 종료 코드 $RC) - 안전을 위해 차단" >&2
fi
exit 2
EOF
chmod +x .claude/hooks/key-guard.sh

시험 키 sample(열린데이터광장의 공개 시험 키, 한 번에 5건)은 여덟 글자보다 짧아 이 패턴에 걸리지 않습니다. /proc/…/environ과 ps e, ps eww처럼 프로세스의 환경 변수(MCP 서버에 넘긴 키 포함)를 엿보는 명령도 막습니다.

2호출 대상 훅: net-guard.sh

Bash 명령과 WebFetch의 URL에서 호스트를 뽑아 openapi.seoul.go.kr이 아니면 막습니다. MCP 서버 자신은 server.py의 BASE_URL 한 곳만 부르도록 코드로 묶여 있습니다.

Terminal, 전체 복사
cd ~/claude-lab/capstone
cat > .claude/hooks/net-guard.sh << 'EOF'
#!/bin/bash
INPUT=$(cat)
command -v jq >/dev/null || { echo "NET: 검사기 오류(jq 없음) - 안전을 위해 차단" >&2; exit 2; }
TEXT=$(printf '%s' "$INPUT" | jq -r '.tool_input | [.. | strings] | join("\n")') \
  || { echo "NET: 입력 해석 실패 - 차단" >&2; exit 2; }

ALLOW="openapi.seoul.go.kr"
HOSTS=$(printf '%s\n' "$TEXT" | grep -oiE "https?://[^/[:space:]\"'<>]+" | sed -E 's#^[A-Za-z]+://##; s#^[^@]*@##; s#:[0-9]+$##' | tr 'A-Z' 'a-z' | sort -u)
for h in $HOSTS; do
  [ "$h" = "$ALLOW" ] || { echo "NET: 허용되지 않은 호출 대상($h). $ALLOW 만 허용됩니다" >&2; exit 2; }
done
exit 0
EOF
chmod +x .claude/hooks/net-guard.sh

4프로젝트 설정에 훅과 deny 규칙 등록

작업 폴더의 .claude/settings.json에 등록합니다. 키 훅은 프롬프트(UserPromptSubmit)와 도구 호출(PreToolUse)을 모두 봅니다. onFailure: block은 스크립트가 없거나 시작하지 못하거나 시간 초과인 경우까지 막습니다(v2.1.295+, 어느 설정 파일의 command 훅에서나 쓸 수 있음, 공식 훅 문서, Ch2 Lab 2 TASK 02 Step 3). permissions.deny는 훅과 별개의 한 겹으로 키가 저장된 ~/.claude.json 읽기와 웹 검색을 막습니다. 다른 트랙에서 만든 settings.json이 있으면 덮어쓰게 되니, 한 트랙만 진행합니다.

Terminal, 전체 복사
cd ~/claude-lab/capstone
cat > .claude/settings.json << 'EOF'
{
  "permissions": {
    "deny": ["Read(~/.claude.json)", "WebSearch"]
  },
  "hooks": {
    "UserPromptSubmit": [
      { "hooks": [{ "type": "command", "command": "$HOME/claude-lab/capstone/.claude/hooks/key-guard.sh", "onFailure": "block" }] }
    ],
    "PreToolUse": [
      { "matcher": "Read|Bash|Write|Edit|WebFetch",
        "hooks": [{ "type": "command", "command": "$HOME/claude-lab/capstone/.claude/hooks/key-guard.sh", "onFailure": "block" }] },
      { "matcher": "Bash|WebFetch",
        "hooks": [{ "type": "command", "command": "$HOME/claude-lab/capstone/.claude/hooks/net-guard.sh", "onFailure": "block" }] }
    ]
  }
}
EOF
jq . .claude/settings.json >/dev/null && echo "settings OK"

이 훅은 도구 입력의 문자열만 봅니다. 스킴 없이 쓴 호스트(curl example.com), 변수로 조립한 URL, 명령의 결과는 보지 못한다는 점은 Ch2 Lab 2에서 확인한 한계와 같습니다. 그래서 agent의 tools에서 Bash와 웹 도구를 빼 둔 것이 또 한 겹이 됩니다. MCP 서버가 실행 중에 보내는 요청도 훅이 보지 않으므로, 서버 쪽 호출 대상은 server.py의 BASE_URL로 묶어 둡니다.

평문 HTTP 서울 열린데이터광장 Open API는 http://openapi.seoul.go.kr:8088 평문 HTTP로만 제공되고, 키가 URL 경로에 들어갑니다. 즉 키는 암호화되지 않은 채 오갑니다. 공용 와이파이 같은 믿을 수 없는 네트워크에서는 실호출하지 않고, 노출이 의심되면 인증키 관리에서 키를 새로 받습니다.
R2에서 쓰입니다 이 폴더의 .claude/agents/, .claude/hooks/, .claude/settings.json, seoul-realestate/가 R2에서 plugin으로 묶을 재료입니다. 키는 plugin 저장소에 들어가지 않고 각 사용자의 MCP 등록에만 있습니다.
