# 2026년 11월 16–17일 FSI 워크샵 eDM

- `eDM.html`: 메일 본문용 HTML. 표 기반 레이아웃과 인라인 스타일을 사용하며, JavaScript·외부 이미지·웹폰트에 의존하지 않습니다.
- `eDM.txt`: 메일 제목, 미리보기 문구, 텍스트 본문.
- `fsi-edm.html`: 웹용 상세 안내. 날짜별 아젠다, 미션 7종, 실습 환경, Slack, 설문 안내를 포함합니다.
- `index.html`: 실습 포털. `labs.zip`의 실습 파일과 이미지를 같은 폴더에 함께 배치했습니다.

## 반영 정보

일정은 **2026년 11월 16일(월)–17일(화)**, 장소는 **센터필드 18층 300·301·400·401호**, 대상은 **금융 서비스 산업(FSI) 고객**입니다.

**양일 10:00–18:00 운영 시간과 상세 시간표는 `labs.zip`의 `labs/fsi-edm.html`을 기준으로 유지했습니다.** 운영 시간은 사용자 별도 확정 정보가 아니므로, 행사 운영 시간 변경 시 메일 HTML·텍스트·상세 페이지에 함께 반영해야 합니다. 메일에서는 연속된 일부 세션만 묶어 표기했습니다.

원본의 캡스톤 수를 실습 포털과 대조하여 정규 선택 미션 6종과 자율 미션 Playbook Foundry 1종으로 구분했습니다. CH 06 Agent SDK도 자율 실습으로 표기했습니다. 원본 eDM과 포털 사이에 서로 다른 모델 버전이 기재되어 있어 이번 안내에서는 특정 모델 버전을 확정하지 않았습니다.

## 활용

브라우저에서 `eDM.html` 또는 `fsi-edm.html`을 열면 확인할 수 있습니다. 웹용 상세 안내를 공유할 때는 같은 폴더의 실습 파일과 `image/`도 함께 호스팅해야 합니다.

메일 제목과 미리보기 문구는 `eDM.txt`에서 복사하고, 메일 발송 도구의 HTML 편집기에 `eDM.html`을 넣으세요. 수신자별 발송 설정과 구독 관리 문구는 사용하는 발송 도구에서 적용합니다.

참가 신청 URL·문의처·신청 마감일·강의실별 배정은 제공되지 않아 임의로 만들지 않았습니다. 현재 메일의 버튼은 원본에 포함된 **실습 Q&A용 Slack 채널**로 연결되며, 참가 신청 버튼이 아닙니다. Slack과 설문 외부 링크는 원본 값을 유지했으며 해당 행사에서의 접근 권한이나 설문 사용 여부는 확인하지 않았습니다.

개별 실습 HTML은 압축파일에서 가져온 자료입니다. Capstone 3에서 압축파일에 포함되지 않은 로컬 웹폰트 CSS 참조 1건과 저장 과정에 섞인 브라우저 확장 프로그램 참조 2건을 제거했습니다. 실습 포털의 작은 화면 줄바꿈도 보정했습니다. 실습 명령·모델 버전·클라우드 배포 내용까지 이번 작업에서 검증한 것은 아닙니다.
