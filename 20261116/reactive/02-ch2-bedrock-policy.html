IAM 권한은 호출, 조회, Marketplace

claude-code-bedrock-policy.json, 호출 2개 + 프로필 조회 2개 + Marketplace

{ "Statement": [
  { "Effect": "Allow",
    "Action": [
      "bedrock:InvokeModel",
      "bedrock:InvokeModelWithResponseStream",
      "bedrock:GetInferenceProfile" ],
    "Resource": [
      "arn:aws:bedrock:*:*:inference-profile/*",
      "arn:aws:bedrock:*:*:application-inference-profile/*",
      "arn:aws:bedrock:*:*:foundation-model/*" ] },
  { "Effect": "Allow",
    "Action": "bedrock:ListInferenceProfiles",
    "Resource": "*" } ] }
// + aws-marketplace:ViewSubscriptions, Subscribe
//   (Condition aws:CalledViaLast = bedrock.amazonaws.com)

항목을 누르면 왼쪽 정책에서 해당 줄이 켜집니다.

모델 호출 권한입니다. 예전 자료에는 이 두 개만 적힌 경우가 많습니다.

inference profile 조회 권한입니다. GetInferenceProfile은 호출과 같은 Resource에, ListInferenceProfiles는 별도 Statement에서 Resource "*"로 둡니다. GetInferenceProfile이 없으면 새 모델마다 한 번 추가 왕복이 생깁니다.

예시는 와일드카드입니다. 실제로는 허용할 profile ARN으로 좁히고, Claude Code 전용 AWS 계정을 권합니다.

aws-marketplace:ViewSubscriptions, Subscribe를 Condition aws:CalledViaLast = bedrock.amazonaws.com으로 묶어 추가합니다.

인터넷 없이 Bedrock만 열려 있다면

망분리 환경에서 먼저 확인할 여덟 가지

항목을 누르면 설정과 참고 사항이 나옵니다.

Bedrock Runtime VPC 엔드포인트

PrivateLink로 인터넷 없이 계정 안에서 추론합니다. VPC 엔드포인트는 이 사설 네트워크 안에서 AWS 서비스로 가는 입구입니다.

IAM Identity Center 포털, OIDC, STS 엔드포인트

SSO 로그인은 Identity Center 포털, OIDC, STS 엔드포인트에 닿아야 합니다. aws sso login이 되는지 먼저 확인합니다.

HTTPS_PROXY, NO_PROXY

사내 프록시를 거쳐야 하는 경우에 설정합니다.

NODE_EXTRA_CA_CERTS

프록시가 TLS를 다시 서명할 때 사내 인증서를 지정합니다.

CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1

자동 업데이트, 오류 리포트 등 외부 통신을 한 번에 끕니다.

사내 배포 + DISABLE_AUTOUPDATER=1

버전을 정해 단말에 배포합니다.

사내 git 마켓플레이스, seed 디렉터리

플러그인도 사내에서 받습니다. Ch5에서 실습합니다.

WebFetch를 deny 또는 허용 도메인만

Bedrock에는 WebSearch가 없습니다 (Ch1).

고정하지 않으면 무엇이 도는가?

QUICK CHECK, 손을 들어 답해 주세요

모델을 고정하지 않은 Bedrock 배포에서 기본 주 모델은?

정답 B. 고정하지 않으면 Opus 단가로 청구됩니다. (amazon-bedrock 문서)

여러 사용자에게 배포하면 반드시 고정

ANTHROPIC_DEFAULT_*와 리전에 따른 prefix 규칙

# managed settings env, 이 랩: us-east-1, global 프로필
ANTHROPIC_DEFAULT_OPUS_MODEL=global.anthropic.claude-opus-5-5
ANTHROPIC_DEFAULT_SONNET_MODEL=global.anthropic.claude-sonnet-5-5
ANTHROPIC_DEFAULT_HAIKU_MODEL=global.anthropic.claude-haiku-5-5

# 고정 대신 prefix만 바꾸기
ANTHROPIC_BEDROCK_REGION_PREFIX=global

허용값: us, eu, apac, jp, au, global. 계정에 있는 profile ID로 채웁니다.

리전을 고르면 prefix가 바뀝니다.

이 랩은 us-east-1에서 global 프로필을 씁니다.
리전 그룹을 고르면 왼쪽 prefix가 바뀝니다.
바뀐 ID는 예시이며, 실제 값은 계정에 있는 profile ID로 확인합니다.

us-로 시작하는 리전은 us. 프로필을 씁니다.

eu-로 시작하는 리전은 eu. 프로필을 씁니다.

서울(ap-northeast-2)을 포함한 ap- 리전은 apac. 프로필을 씁니다.

그 밖의 리전은 global. 프로필을 씁니다.

팀별 비용은 프로필 ARN이 가른다

Application inference profile로 경로와 비용 경계를 고정

모델 말고도 청구서를 바꾸는 세 설정

서비스 티어, 1M 컨텍스트, 프롬프트 캐시

설정을 누르면 키와 주의할 점이 나옵니다.

ANTHROPIC_BEDROCK_SERVICE_TIER

default, flex, priority 중에서 골라 비용과 지연을 맞바꿉니다. 모델과 리전마다 지원이 다릅니다.

[1m] 접미사

[1m] 접미사는 4.6 모델만 씁니다. Sonnet 5+, Opus 4.7+는 기본 1M입니다. 긴 컨텍스트는 곧 큰 요청입니다.

Prompt caching

기본 5분 TTL입니다. ENABLE_PROMPT_CACHING_1H는 더 비쌉니다. 리전과 모델별 지원을 확인합니다.
