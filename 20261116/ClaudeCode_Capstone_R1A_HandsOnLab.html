03

가드레일

25분

개인정보 패턴과 원본 raw/ 접근을 막는 훅을 fail-closed로 등록합니다.

가드레일을 두 겹으로 둡니다. 개인정보 패턴은 Ch2 Lab 2에서 만든 dlp-guard.sh를 가져와 쓰고, 원본 raw/ 접근은 같은 방식의 훅을 새로 만듭니다. 원리는 Ch2 Lab 2 가드레일과 DLP와 같습니다. 훅에서 exit 2가 차단이고, 오류 경로에서도 exit 2를 내야 fail-closed입니다.

1raw/ 차단 훅 만들기

dlp-guard.sh는 체크포인트에 있는 그대로 두고(jq 없음, 입력 해석 실패, grep 오류에서 모두 exit 2), raw-guard.sh는 같은 모양으로 씁니다. 도구 입력에 mydata/raw 또는 raw/가 들어 있으면 막습니다.

Terminal, 전체 복사
cd ~/claude-lab/capstone
cat > .claude/hooks/raw-guard.sh << 'EOF'
#!/bin/bash
INPUT=$(cat)
command -v jq >/dev/null || { echo "RAW: 검사기 오류(jq 없음) - 안전을 위해 차단" >&2; exit 2; }
TEXT=$(echo "$INPUT" | jq -r '.tool_input | tostring') || { echo "RAW: 입력 해석 실패 - 차단" >&2; exit 2; }

PAT='mydata/raw|(^|[^A-Za-z0-9_.-])raw/'
echo "$TEXT" | grep -Eq "$PAT"; RC=$?
[ "$RC" -eq 1 ] && exit 0      # 1 = 패턴 없음 → 통과
if [ "$RC" -eq 0 ]; then
  echo "RAW: 원본(raw/) 접근은 차단됩니다. pseudo/ 가명 데이터를 쓰세요" >&2
else
  echo "RAW: 검사기 오류(grep 종료 코드 $RC) - 안전을 위해 차단" >&2
fi
exit 2
EOF
chmod +x .claude/hooks/raw-guard.sh
echo '{"tool_input":{"file_path":"/Users/me/claude-lab/mydata/raw/customers.csv"}}' | .claude/hooks/raw-guard.sh; echo "exit=$?"
echo '{"tool_input":{"command":"cat raw/cards.csv"}}' | .claude/hooks/raw-guard.sh; echo "exit=$?"
echo '{"tool_input":{"file_path":"/Users/me/claude-lab/capstone/pseudo/customers.csv"}}' | .claude/hooks/raw-guard.sh; echo "exit=$?"
echo '{"prompt":"고객 900101-1234567 의 가입 이력"}' | .claude/hooks/dlp-guard.sh; echo "exit=$?"
echo '{"prompt":"안녕하세요"}' | .claude/hooks/dlp-guard.sh; echo "exit=$?"

다섯 줄 중 raw 두 줄과 주민번호 줄은 exit=2, pseudo/ 경로와 "안녕하세요"는 exit=0이 나와야 합니다. 이 훅은 도구 입력의 문자열 패턴만 봅니다. 경로를 돌려 쓰는 명령(예: 글로브)이나 실행 결과는 보지 못한다는 점은 Ch2 Lab 2에서 확인한 한계와 같습니다.

2프로젝트 설정에 훅과 deny 규칙 등록

작업 폴더의 .claude/settings.json에 등록합니다. 프롬프트는 UserPromptSubmit, 도구 호출은 PreToolUse가 검사합니다. onFailure: block은 스크립트가 없거나 시작하지 못하거나 시간 초과인 경우까지 막습니다(v2.1.295+, 어느 설정 파일의 command 훅에서나 쓸 수 있음, 공식 훅 문서, Ch2 Lab 2 TASK 02 Step 3). permissions.deny는 훅과 별개의 한 겹으로 raw/ 읽기를 막습니다.

Terminal, 전체 복사
cd ~/claude-lab/capstone
cat > .claude/settings.json << 'EOF'
{
  "permissions": {
    "deny": ["Read(~/claude-lab/mydata/raw/**)"]
  },
  "hooks": {
    "UserPromptSubmit": [
      { "hooks": [{ "type": "command", "command": "$HOME/claude-lab/capstone/.claude/hooks/dlp-guard.sh", "onFailure": "block" }] }
    ],
    "PreToolUse": [
      { "matcher": "Bash|Write|Edit|WebFetch",
        "hooks": [{ "type": "command", "command": "$HOME/claude-lab/capstone/.claude/hooks/dlp-guard.sh", "onFailure": "block" }] },
      { "matcher": "Read|Grep|Glob|Bash|Write|Edit",
        "hooks": [{ "type": "command", "command": "$HOME/claude-lab/capstone/.claude/hooks/raw-guard.sh", "onFailure": "block" }] }
    ]
  }
}
EOF
jq . .claude/settings.json >/dev/null && echo "settings OK"
R2에서 쓰입니다 이 폴더의 .claude/agents/, .claude/hooks/, .claude/settings.json이 R2에서 plugin으로 묶을 재료입니다. 훅 경로의 $HOME/claude-lab/capstone은 그때 plugin 경로로 바뀝니다.

3고장 난 훅도 막는지 (fail-closed)

세션을 /exit로 나온 뒤, raw-guard.sh를 잠깐 치우고, 도구 호출이 필요한 무해한 프롬프트를 보냅니다. raw-guard.sh는 PreToolUse에만 등록돼 있어서 도구 호출이 없는 프롬프트에서는 실행되지 않기 때문입니다. 스크립트가 없는데도 도구 호출이 막히면 fail-closed입니다. 마지막 줄에서 반드시 되돌립니다.

Terminal, 전체 복사
cd ~/claude-lab/capstone
mv .claude/hooks/raw-guard.sh .claude/hooks/raw-guard.sh.off
claude -p "pseudo/customers.csv 첫 줄을 읽어줘"; echo "claude exit=$?"
mv .claude/hooks/raw-guard.sh.off .claude/hooks/raw-guard.sh
ls .claude/hooks

Read 도구 호출이 훅 오류로 차단되어 파일 내용이 나오지 않고, PreToolUse:Read 훅 오류와 onFailure 차단을 알리는 메시지가 보여야 합니다. 메시지 문구는 버전에 따라 다를 수 있으니 실제로 나온 문구를 기록해 둡니다. 첫 줄이 그대로 출력됐다면 onFailure 줄과 Claude Code 버전(claude --version)을 확인합니다.
