Claude Code를 개인의 도구에서 팀의 개발 플랫폼으로 연결하는 이틀입니다. 금융 서비스 산업 고객을 대상으로, Amazon Bedrock 기준의 배포와 정책, 가드레일과 DLP, 전문 에이전트와 플러그인, 토큰과 비용 통제까지 공식 문서를 기준으로 실습하며 익힙니다.

Day 1은 개인의 도구에서 조직의 통제로 가는 흐름입니다. 작동 원리에서 출발해 Bedrock 배포와 managed settings, DLP 5층 가드레일을 직접 적용하고 Subagent로 일을 나눠 맡깁니다. 오후에는 고객 마이데이터, 서울 부동산 공공데이터, 내가 고른 MCP 중 하나를 골라 나만의 agents와 가드레일을 만듭니다.

Day 2는 팀의 플랫폼으로 확장하고 측정하는 날입니다. 플러그인과 mods로 팀 표준을 배포하고, 컨텍스트 엔지니어링으로 토큰을 아낍니다. 오후에는 첫날의 agents를 plugin 하나로 묶어 마켓플레이스에 배포하고, 새 폴더에서 설치해 서로 다른 업무 두 가지에 다시 씁니다. 이어서 이틀간 사용한 토큰을 대시보드로 확인하고, Claude Apps Gateway에서 사용자 지출 한도를 직접 걸어 보며 조직의 비용 통제를 정리합니다.
