R2-1 정기 분석 리포트: 설치한 plugin으로 같은 형식의 리포트를 반복해서 만들기

R2 공통 단계에서 설치한 plugin의 skill과 agent만으로 정해진 형식의 분석 리포트를 두 번 만들고, 그동안 agent와 skill을 하나도 새로 짜지 않았음을 확인한다

정기 리포트의 핵심은 매번 같은 절차, 같은 형식입니다. 그 절차와 형식은 이미 periodic-report skill에 들어 있습니다. 이 미션에서는 동료 폴더 ~/claude-lab/capstone-try/에서 /my-kit:periodic-report를 대상이나 기간만 바꿔 두 번 돌리고, 결과의 형식이 같은지, 쓴 agent와 skill이 모두 plugin에서 왔는지 봅니다. R2 공통 단계를 먼저 끝내야 합니다.

시작 전 확인

5분

동료 폴더에 plugin이 설치돼 있고, 설치할 때 남긴 agent와 skill 지문이 그대로인지 봅니다.

Terminal, 전체 복사
cd ~/claude-lab/capstone-try && . ~/claude-lab/capstone/r2.env
claude plugin list
(cd ~/claude-lab/capstone/marketplace/plugins/$KIT && sha256sum -c ~/claude-lab/capstone-try/kit.sha)
ls -A .claude

my-kit@capstone-local이 Scope: local, ✔ enabled로 보이고, sha256sum -c의 줄이 모두 OK, .claude/에는 settings.json과 settings.local.json만 있으면 됩니다. kit.sha가 없으면 R2 공통 04의 3번 블록을 먼저 실행합니다.

plugin의 skill을 명령으로 불러 첫 정기 리포트를 reports/에 만듭니다.

Terminal
cd ~/claude-lab/capstone-try && claude

트랙 B는 키를 넣지 않았다면 mock이라 건물명이 "샘플"로 시작합니다. 202609와 202610은 샘플에 모두 들어 있어 두 번째 리포트에서 직전 대비 비교가 됩니다. 트랙 C alphavantage는 무료 키가 하루 25회라 리포트 두 번이면 충분합니다. 도중에 도구 사용 허락을 물으면 허락합니다. 화면에 my-kit:이 붙은 agent 이름이 지나가는 것을 봅니다.

끝나면 두 번째 터미널에서 결과의 제목 줄을 봅니다.

Terminal 2, 전체 복사
cd ~/claude-lab/capstone-try
ls -l reports/
for f in reports/*.md; do echo "== $f"; grep -E '^#' "$f" | head -8; done

skill의 출력 형식대로 요약, 핵심 표, 눈에 띄는 변화와 이유, 확인하지 못한 것, 검토 결과의 다섯 항목이 그 순서로 있어야 합니다. 형식이 다르면 skill을 고치지 말고 세션에서 "periodic-report의 출력 형식 그대로 다시 정리해 주세요"라고 요청합니다.

가드레일에 막히면 리포트를 만드는 도중에 DLP:, KEY:, NET:, MCP:로 시작하는 메시지가 나오면 가드레일이 제 일을 한 것입니다. 우회하지 말고, 어떤 요청이 막혔는지 화면을 남겨 두면 출품 양식 4번에 쓸 수 있습니다.

02

같은 형식으로 한 번 더

10분

대상이나 기간만 바꿔 같은 명령을 다시 보내고, 두 리포트의 형식이 같은지 봅니다.

01 표의 두 번째 칸을 보냅니다. 같은 세션이어도 되고 새 세션이어도 됩니다. 같은 대상의 지난 리포트가 있으면 skill의 절차대로 "눈에 띄는 변화와 이유"에서 지난 리포트와 비교합니다(트랙 B 강남구 202609와 202610, 트랙 C alphavantage 9월과 10월).

끝나면 01의 Terminal 2 블록을 다시 실행해 두 파일의 제목 줄이 같은 다섯 항목인지 봅니다. 프롬프트로 형식을 길게 설명하지 않았는데도 형식이 같다면, 형식은 프롬프트가 아니라 skill에서 왔다는 뜻입니다.

정기 실행으로 넓히려면 매주 같은 시각에 돌리는 일은 이번 미션의 범위 밖입니다. 이 skill은 명령 한 줄로 불리므로, 나중에 같은 명령을 정해 둔 일정으로 실행하게 해도 결과의 형식은 그대로입니다.

03

재사용 확인

10분

두 리포트를 만드는 동안 agent와 skill을 하나도 새로 짜지 않았고, 쓴 것이 모두 설치한 plugin에서 왔음을 보입니다.

Terminal 2, 전체 복사
cd ~/claude-lab/capstone-try && . ~/claude-lab/capstone/r2.env
(cd ~/claude-lab/capstone/marketplace/plugins/$KIT && sha256sum -c ~/claude-lab/capstone-try/kit.sha)
find . -path ./.git -prune -o \( -path '*/agents/*' -o -name SKILL.md \) -print
claude plugin details $KIT@capstone-local | grep -E 'Skills|Agents|Hooks|MCP servers'

세 가지를 봅니다. sha256sum -c가 모두 OK면 설치 뒤에 plugin의 agent와 skill이 바뀌지 않았습니다. find가 아무것도 출력하지 않으면 이 폴더에 따로 만든 agent나 skill이 없습니다. claude plugin details의 수는 R2 공통 04에서 본 것과 같아야 합니다.

세션에서도 물어봅니다.

Claude 세션 입력
이번 세션에서 쓴 skill과 subagent의 이름을 모두 적고, 각각 어디서 왔는지(plugin 이름, 또는 이 폴더) 알려 주세요.

답에 my-kit:periodic-report와 my-kit:이 붙은 agent만 나오면 됩니다. 이 답은 모델의 설명이라 보조 증거이고, 지문 검사가 기준입니다.

skill을 고치고 싶어졌다면 두 번 돌려 보니 형식을 바꾸고 싶을 수 있습니다. 그때는 이 폴더에 새 skill을 만들지 말고, ~/claude-lab/capstone/my-kit/ 원본을 고친 뒤 버전을 올리고 R2 공통 03으로 다시 배포합니다. 그다음 R2 공통 04의 3번 블록으로 kit.sha를 다시 만들고, 바꾼 내용을 출품에 적습니다. 업무마다 agent와 skill을 새로 짜는 것이 아니라, 하나의 plugin을 고쳐 가며 쓰는 것이 재사용입니다.

정리

5분

리포트에 개인정보 패턴과 키가 없는지 보고, 출품에 쓸 메모를 남깁니다.

Terminal 2, 전체 복사
cd ~/claude-lab/capstone-try
grep -nE '[0-9]{6}-[1-4][0-9]{6}|[0-9]{4}-[0-9]{4}-[0-9]{4}-[0-9]{4}|01[016789]-[0-9]{3,4}-[0-9]{4}' reports/*.md || echo "개인정보 패턴 없음"
jq -r '.. | objects | (.SEOUL_API_KEY?, .ALPHA_VANTAGE_API_KEY?, .Authorization?) | strings | sub("^Bearer "; "")' ~/.claude.json 2>/dev/null \
  | while IFS= read -r V; do [ ${#V} -ge 8 ] && grep -rlF -- "$V" reports/ ; done
echo "키 검사 끝 (위에 파일 이름이 나오면 그 파일에 키나 토큰이 있습니다)"

개인정보 패턴 없음과 키 검사 끝 사이에 파일 이름이 없으면 됩니다. 아래는 트랙 B의 메모 예입니다. 내 트랙에 맞게 바꿔 둡니다.

출품 메모, 예시
[R2-1 정기 분석 리포트]
plugin: my-kit 0.1.0 (트랙 B), 설치: /plugin install my-kit@capstone-local
같은 형식으로 두 번: reports/202609-강남구.md, reports/202610-강남구.md
쓴 것: /my-kit:periodic-report, my-kit:price-summarizer, my-kit:anomaly-checker (새로 짠 agent, skill 없음, kit.sha 모두 OK)

R2 미션은 두 개 이상입니다. 다음은 R2-2 기획안 작성이 이 리포트를 근거로 이어집니다. 다른 미션은 개요의 R2 미션에서 고릅니다. 정식 출품은 출품 양식으로 하고, 완주 체크리스트 6번은 두 번째 미션까지 끝낸 뒤 채웁니다.
