금융 서비스 산업 고객 여러분을 Claude Code Deep Dive Workshop에 초대합니다.

Amazon Bedrock 기준의 배포와 정책, 가드레일과 DLP, 전문 에이전트와

나만의 agents와 plugin을 만드는 캡스톤
- R1 (Day 1): 미션 셋 중 하나를 골라 내 agents와 가드레일을 만듭니다.
  R1-A 고객 맞춤 서비스(마이데이터), R1-B 서울 부동산 시세(공공데이터 MCP 직접 제작), R1-C 내가 고른 MCP
- R2 (Day 2): R1의 agents를 plugin으로 묶어 마켓플레이스에 배포하고, 새 폴더에서 설치해 씁니다.
  이어서 R2-1 정기 분석 리포트, R2-2 기획안 작성, R2-3 AgentCore 앱(선택) 중 두 개 이상을 해 냅니다.
- 출품: Slack에 plugin 설치 명령, 업무 두 가지 결과, 가드레일이 막은 장면을 올립니다.
- 지난 출품작: https://capstone.atomai.click/
- 자율 실습: Playbook Foundry(예전 캡스톤 예시), Agent SDK
