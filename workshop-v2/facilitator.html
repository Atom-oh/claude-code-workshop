진행자 가이드

운영, 막힘 대응, 비용 예산, 검증 상태

진행자와 보조가 행사 전후에 보는 문서입니다. 행사 때 참가자에게 배포하지 않습니다(팀 검토용 링크는 포함).

대상: 진행자·보조

역할과 인원

역할인원 제안하는 일
메인 진행자1설명 15분, 시연, 시간 관리
보조참가자 15명당 1~2막힘 해결, 페어링, 환경 문제 대응
트랙 리드트랙당 1트랙 A, B, C 실습 지원(트랙 C는 AWS 리소스와 수집기 준비 필요)

막힘 정책: 10분 규칙

  1. 혼자 10분 시도
  2. 랩의 힌트 카드 열기
  3. 옆 사람(짝)에게 묻기
  4. 보조 호출

먼저 끝난 사람은 보너스 카드로 갑니다. 진행 속도 차이를 줄이려고 체크포인트 체크박스(브라우저에 저장됨)를 화면에 띄워 두고 막힌 단계가 어디인지 봅니다.

수준 차이 장치

  • 짝 실습: 사전 과제의 숙련도 자기 평가로 숙련자와 입문자를 짝지음(숙련자는 대신 입력하지 않고 설명만).
  • 3단 랩: 기본 레일 / 보너스 / 힌트.
  • 개념 예산: 9개를 쓰기 직전에 하나씩. 15분에 하나를 넘기지 않음.
  • 효과 측정: 설문에 "가장 어려웠던 블록"과 "내 업무에 쓸 수 있는가"를 추가해 다음 회차에 반영.

흔한 막힘과 대응 (이 자료를 준비하며 실제로 겪은 것)

증상원인대응
프로젝트 .claude/settings.json의 허용 규칙이 안 먹는다허용 규칙은 폴더 신뢰 대화상자를 거친 뒤에만 적용. claude -p는 대화상자가 없어 보류됨대화형에서 신뢰 수락. 비대화형은 --allowedTools나 추적되지 않는 settings.local.json
서브에이전트가 Bash 승인 대기에 걸린다tools는 쓸 수 있는 도구, 승인 없는 실행은 허용 규칙(별개). 규칙은 명령 모양이 일치할 때만 적용(cd, ;, echo를 붙이면 불일치)정의 파일에 '정확히 한 줄만 실행' 명시, 허용 규칙 추가
훅이 안 돈다--safe-mode는 --settings로 넣은 훅까지 끔. 스크립트 실행 권한, 신뢰 미수락도 원인플래그 제거, chmod +x, 신뢰 수락
PostToolUse에서 exit 2를 줬는데 막히지 않는다PostToolUse는 이미 실행된 뒤라 차단이 아님차단은 PreToolUse 또는 onFailure: "block", 종료 막기는 Stop 훅
OTel 수신기에 안 뜬다 / 포트 충돌기본 포트가 이미 사용 중이거나 사용자 settings.json의 OTel env가 셸 변수를 덮어씀수신기는 14318 사용, --settings의 env가 우선
비용 숫자가 자료와 다르다환경(플러그인·스킬·MCP)에 따라 컨텍스트가 다르고, 캐시 상태에 따라 요동--safe-mode로 깨끗한 기준 측정, 비율과 구성(캐시 생성 토큰)을 보게 안내
예산 상한을 넘겨서 멈췄다예산은 턴이 끝난 뒤 검사. 클라이언트 추정치 기준상한을 작업 비용보다 여유 있게, 이것이 학습 포인트임을 설명
Claude가 이전 세션의 일을 언급한다자동 메모리가 같은 폴더의 이전 세션 내용을 기억할 수 있음(측정 중 실제로 발생)필요 시 새 폴더에서 시작하거나 자동 메모리를 끔(공식 문서의 CLAUDE_CODE_DISABLE_AUTO_MEMORY, 이 자료에서는 실행 안 함)
make_seed.py를 다시 돌렸더니 양식이 예전으로 돌아갔다스크립트가 template/을 H열 없는 원래 양식으로 덮어씀양식을 바꾼 뒤에는 실행하지 않음
worktree 안에서 npm test가 승인 대기허용 규칙이 그 실행 형태와 맞지 않을 수 있음사람이 그 worktree에서 직접 테스트
엑셀 파일을 Read로 읽으려 한다xlsx는 압축 바이너리Python(openpyxl)으로 열도록 규칙에 명시(CLAUDE.md)

사전 준비 체크리스트

  1. D-14: 환경 확정(제공 환경 또는 개인 노트북), 모델 연결(Bedrock 등), 계정·쿼터 확인(참가자 수 × 동시 호출이 한도를 넘지 않는지).
  2. D-7: 프리플라이트 배포와 회신 수집, 업무 PC 확인 질문 회신.
  3. D-3: 회신 미제출자와 막힌 사람에게 대체 경로 안내, 트랙 배정.
  4. D-2: 리허설: 각 페이지의 명령을 새 환경에서 처음부터 끝까지 실행(모델 호출 비용 발생).
  5. D-1: 트랙 C 환경(AWS 리소스, 수집기)과 관리형 정책 배포용 전용 환경 준비. 공용 환경에는 정책을 배포하지 않음.
