프리플라이트 체크

대체 경로 (3단)

  1. 제공 환경: 주최 측이 안내하는 브라우저 기반 환경에서 위 점검을 통과하면 그대로 진행.
  2. 개인 노트북: 설치 후 위 점검을 다시 실행. macOS·Linux·WSL은 curl -fsSL https://claude.ai/install.sh | bash, Windows PowerShell은 irm https://claude.ai/install.ps1 | iex (공식 설치 문서). 모델 연결 정보는 주최 측이 별도 안내.
  3. 현장 짝 실습: 위 둘 다 어려우면 옆 사람과 한 화면으로 진행하고, 결과물은 이후 환경에서 다시 만들어 봅니다.
회사 네트워크 허용 도메인공식 네트워크 요건에 나온 주요 도메인입니다. 표는 요약이므로 보안팀에 요청할 때는 공식 문서의 최신 표를 첨부하세요.

업무 PC 확인 질문 4개

문서 보안(DRM)이나 화면 캡처 차단이 걸린 단말은 공식 문서에 동작이 설명되어 있지 않습니다. 해결을 약속하지 않고 사전에 확인만 받아 현장 지원 계획에 씁니다.

  1. 업무 PC에서 터미널(또는 브라우저 기반 터미널)을 열 수 있나요?
  2. 문서 보안(DRM)이 걸린 파일을 터미널이나 코드 도구로 열면 어떻게 되나요? (열림 / 열리지 않음 / 모름)
  3. 화면 캡처나 화면 공유가 막혀 있어서 가이드를 보면서 따라 하기 어렵지는 않나요? (두 번째 기기나 인쇄본이 필요한가요?)
  4. 회사 프록시나 인증서 검사 때문에 외부 사이트 접속이 제한되나요? (허용 도메인 요청이 필요한가요?)

사전 과제 (참가자별 1개)

트랙 배정과 질문 클리닉에 씁니다. 실제 고객·내부 자료는 적지 마세요.

  1. 이번 달에 사람이 반복하는 일 하나를 적어 주세요. (예: 월간 점검 보고서 작성)
  2. 그 일의 입력 자료는 무엇이고, 결과물은 어떤 형태(양식)인가요? (실제 자료가 아니라 종류만 적어 주세요)
  3. 한 달에 몇 번, 한 번에 얼마나 걸리나요?
  4. 결과가 틀리면 어떤 일이 생기나요? (그래서 무엇을 가장 확인하고 싶은가요?)

데이터 원칙

실습에는 가상 데이터만 씁니다. 실제 고객정보, 내부 자료, 규제기관 제출 자료는 반입하지 않습니다. 대화 기록은 로컬에 평문으로 저장되므로 비밀번호와 키를 프롬프트에 붙여 넣지 마세요.
