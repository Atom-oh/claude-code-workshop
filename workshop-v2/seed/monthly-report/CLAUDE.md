# 월간 점검 보고서 (연습용 가상 데이터)

- 숫자 계산은 반드시 Python 코드로 한다. 직접 암산하거나 추정하지 않는다.
- 양식 `template/월간점검보고서_양식.xlsx`를 복사해 노란 칸(B4:G7)만 채운다. 제목, 병합 셀, 열 너비, 서식은 바꾸지 않는다. 바꿀 수 있는 것은 A2의 점검월 문구뿐이다(`점검월: YYYY-MM / 노란 셀만 입력하세요`).
- 비율은 소수 첫째 자리까지 반올림한다(사사오입). 의심비율 = 의심건수 / 판매건수 × 100, 전월대비 증감률 = (이번 달 − 전월) / 전월 × 100.
- 결과는 `output/월간보고.xlsx`에 저장한다.
- 실제 고객·내부 자료를 사용하지 않는다. 이 폴더의 데이터는 모두 가상이다.
