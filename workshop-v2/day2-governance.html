키효과비고
permissions.disableBypassPermissionsMode모든 확인을 건너뛰는 bypassPermissions 모드를 막음어느 설정 파일에서도 쓸 수 있으나 관리형에 두면 사용자가 바꿀 수 없음
allowManagedHooksOnly사용자·프로젝트·로컬·플러그인 훅 차단, 조직이 배포한 훅만 실행관리형 enabledPlugins로 강제한 플러그인의 훅은 예외
extraKnownMarketplaces + strictKnownMarketplaces + enabledPlugins허용한 사내 마켓만 쓰고 지정 플러그인은 강제 설치등록하려는 마켓의 출처도 허용 목록을 통과해야 함
disableSideloadFlags--plugin-dir 등 목록 밖 로드 경로 차단
allowManagedMcpServersOnly + 빈 allowedMcpServers관리형 목록에 없는 MCP 서버 전부 차단serverName 항목은 보안 통제가 아님. URL이나 명령으로 지정
pluginConfigs.cc-plugin-sec-default@builtin.options.allowManagedModsOnly사용자가 가져온 mod 차단 (mod는 샌드박스 밖에서 사용자 권한으로 실행됨)조직 mod로 인정되려면 로컬 디렉터리 마켓 등 조건이 있음
cleanupPeriodDays로컬 대화 기록(평문) 보존 기간기본 30일
env (OTel 변수)사용량·비용 지표를 사내 수집기로 전송team.id는 개발자 측 설정이라 변조 가능. 관리형 env로 고정
allowManagedHooksOnly는 코어 2의 Stop 게이트도 막습니다프로젝트 .claude/settings.json의 훅은 이 설정이 켜지면 실행되지 않습니다. 게이트를 쓰려면 조직이 같은 훅을 관리형 훅으로 승격해 배포해야 합니다. 개별 편의와 조직 통제가 부딪히는 대표적인 지점입니다(공식 문서 기준, 이 자료에서는 관리형 배포를 실행하지 못했습니다).

3OTel로 팀별 비용 집계

수집기가 없어도 되도록 표준 라이브러리로 만든 작은 수신기를 씁니다(127.0.0.1만 수신). 한 터미널에서 수신기를 띄우고 다른 터미널에서 두 팀이 호출합니다.

Terminal 1
cat > otlp_sink.py <<'WV2EOF'
#!/usr/bin/env python3
"""연습용 OTLP/HTTP(JSON) 수신기. 표준 라이브러리만 쓴다. 127.0.0.1에서만 받는다.
Claude Code가 보내는 claude_code.cost.usage 지표를 team.id, model, query_source별로 합산해 출력한다.
사용: python3 otlp_sink.py [포트]   (기본 14318)
"""
import json, sys
from collections import defaultdict
from http.server import BaseHTTPRequestHandler, HTTPServer

TOTAL = defaultdict(float)


def attr_map(attrs):
    out = {}
    for a in attrs or []:
        v = a.get("value", {})
        out[a["key"]] = next(iter(v.values())) if v else None
    return out


class H(BaseHTTPRequestHandler):
    def do_POST(self):
        body = self.rfile.read(int(self.headers.get("Content-Length", 0)))
        try:
            data = json.loads(body)
        except Exception:
            self.send_response(415); self.end_headers(); return
        if self.path.endswith("/v1/metrics"):
            for rm in data.get("resourceMetrics", []):
                res = attr_map(rm.get("resource", {}).get("attributes"))
                for sm in rm.get("scopeMetrics", []):
                    for m in sm.get("metrics", []):
                        if m.get("name") != "claude_code.cost.usage":
                            continue
                        for dp in (m.get("sum") or m.get("gauge") or {}).get("dataPoints", []):
                            a = {**res, **attr_map(dp.get("attributes"))}
                            val = dp.get("asDouble", dp.get("asInt", 0))
                            key = (a.get("team.id", "-"), a.get("model", "-"), a.get("query_source", "-"))
                            TOTAL[key] = max(TOTAL[key], float(val))  # 누적(cumulative) 값이므로 최댓값을 쓴다
            print("\n팀 | 모델 | 호출 유형 | 누적 비용(USD)")
            for (t, mo, q), v in sorted(TOTAL.items()):
                print(f"{t} | {mo} | {q} | {v:.4f}", flush=True)
        self.send_response(200); self.send_header("Content-Type", "application/json"); self.end_headers(); self.wfile.write(b"{}")

    def log_message(self, *a):
        pass


if __name__ == "__main__":
    port = int(sys.argv[1]) if len(sys.argv) > 1 else 14318
    print(f"OTLP 수신 대기: http://127.0.0.1:{port}/v1/metrics", flush=True)
    HTTPServer(("127.0.0.1", port), H).serve_forever()
WV2EOF

4감사 훅: 도구 호출을 JSONL로 남기기

cat > audit_hook.py <<'WV2EOF'
#!/usr/bin/env python3
"""연습용 감사 훅. PreToolUse 이벤트마다 한 줄(JSONL)을 남긴다. 값 전체가 아니라 요약만 기록한다.
훅은 stdin으로 JSON을 받는다. 이 스크립트는 아무것도 막지 않는다(항상 exit 0)."""
import json, os, sys, time

AUDIT = os.environ.get("AUDIT_LOG", os.path.expanduser("~/claude-audit.jsonl"))
try:
    ev = json.load(sys.stdin)
except Exception:
    sys.exit(0)
inp = ev.get("tool_input") or {}
summary = inp.get("command") or inp.get("file_path") or inp.get("pattern") or inp.get("url") or ""
rec = {
    "ts": time.strftime("%Y-%m-%dT%H:%M:%S%z"),
    "session": ev.get("session_id"),
    "event": ev.get("hook_event_name"),
    "tool": ev.get("tool_name"),
    "target": str(summary)[:160],
    "cwd": ev.get("cwd"),
}
with open(AUDIT, "a", encoding="utf-8") as f:
    f.write(json.dumps(rec, ensure_ascii=False) + "\n")
sys.exit(0)
WV2EOF

5폐쇄망 질문에 답하기: 가능 / 불가능 / 검증 필요
항목라벨근거와 한계
모델 트래픽을 Bedrock 또는 사내 LLM 게이트웨이로 고정 (allowedProviders)가능게이트웨이는 Anthropic 형식을 받아야 하고 인증·사용량·예산·감사는 게이트웨이가 담당
텔레메트리·업데이트·비필수 트래픽 차단가능DISABLE_TELEMETRY(비어 있지 않은 값, 0은 끄지 못함), CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC, DISABLE_UPDATES
프록시, 사설 CA, mTLS가능HTTPS_PROXY, NODE_EXTRA_CA_CERTS, 클라이언트 인증서 변수. SOCKS는 미지원
플러그인을 인터넷 없이 배포가능CLAUDE_CODE_PLUGIN_SEED_DIR 읽기 전용 시드 + 사내 마켓
훅·MCP·마켓·mod 잠금, 감사 이벤트(OTel tool_decision 등)가능관측 수준의 통제. 프롬프트는 기본적으로 가려지고 로컬 기록은 평문
샌드박스로 Bash 하위 프로세스 격리조건부macOS, Linux, WSL2만. 네이티브 Windows는 샌드박스 없음. 파일 도구, MCP, 훅은 샌드박스 밖
완전 오프라인 사용불가모델 엔드포인트에 닿는 경로가 반드시 필요
Bedrock 사용 시 WebSearch, /logout불가Bedrock에서는 지원되지 않음
Bedrock VPC 인터페이스 엔드포인트(PrivateLink) 위의 Claude Code검증 필요AWS는 bedrock-runtime 엔드포인트를 제공하지만 Claude Code 문서는 PrivateLink를 언급하지 않음. vpce 호스트명에서의 동작은 직접 확인
인터넷 경로가 전혀 없는 서브넷에서의 시작 점검검증 필요문서가 텔레메트리·비필수 트래픽 차단을 권장하나 시작 시 점검의 동작은 직접 확인
사내 npm·GitHub 미러, 프록시 뒤 게이트웨이검증 필요플러그인·마켓별로 필요 여부 확인
DRM 문서, 화면 캡처 차단, 클립보드 제한, VDI문서 없음공식 문서에 동작이 없음. 고객 단말에서 직접 검증 필요
6고객 환경에서 사전에 검증할 7가지
  1. 모델 엔드포인트(Bedrock 또는 게이트웨이)에 업무 단말에서 닿는가? (프리플라이트의 모델 호출)
  2. 프록시와 사설 CA를 환경 변수로 지정했을 때 통과하는가?
  3. 텔레메트리·업데이트·비필수 트래픽을 끈 상태로 시작되는가?
  4. Bedrock PrivateLink를 쓸 경우 vpce 호스트명으로 호출이 성공하는가? (SigV4 호스트·리전 처리)
  5. 플러그인 설치에 외부 접근이 필요한가? 시드와 사내 마켓으로 대체되는가?
  6. DRM이 걸린 문서를 도구가 읽을 수 있는가? 없다면 업무 흐름은 무엇인가?
  7. 화면 캡처·공유 제한이 있는 단말에서 가이드를 어떻게 볼 것인가?
Day 2 통제 체크포인트
보너스 (먼저 끝낸 분)
  • OTel 수신기의 집계 키에 effort를 추가해 effort별 비용도 봅니다.

힌트 (막혔을 때)
  • 포트 충돌: 수신기 기본 포트는 14318입니다. 이미 사용 중이면 다른 포트로 띄우고 OTEL_EXPORTER_OTLP_ENDPOINT도 같게 바꾸세요.
  • 설정 파일의 OTel 변수와 충돌: 사용자 settings.json의 env에 이미 OTel이 설정되어 있으면 셸 변수가 덮어써집니다. --settings의 env가 우선합니다.
검증 기록 (2026-10-21, Claude Code 2.1.306)
