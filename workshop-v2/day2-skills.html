Day 2 · 내 업무를 Skill로

반복 업무를 이름 붙은 절차로, 팀 표준으로

개인의 방식을 한 줄로 재실행 가능한 절차로 만들고 검증과 배포까지 묶습니다.

70분개념 1개 (Skill)

이 블록에서 하는 일

"암묵지를 Skill로 만들어 팀 표준으로 배포하고 싶다", "조직의 AI 활용 수준을 고르게 올리고 싶다"는 요구에 답합니다. 개인이 잘하는 사람의 방식을 이름 붙은 절차로 만들면 다른 사람도 같은 품질로 반복할 수 있습니다.

항목내용
시간70분
이어서코어 2의 폴더(~/workshop/monthly-report)
완료 기준다음 달 데이터로 /monthly-report 한 줄이 대조를 통과하고, 팀 마켓 형태로 검증을 통과한다

설명 15분

  • Skill은 SKILL.md 파일입니다. 이름, 설명, 순서를 적고 /이름으로 호출합니다. disable-model-invocation: true이면 사람이 부를 때만 실행됩니다. 보고서처럼 부수 효과가 있는 작업에 적합합니다.
  • 팀 표준은 플러그인으로 묶고 마켓에서 설치하게 하는 것입니다. 조직은 허용하는 마켓만 쓰도록 정책으로 제한할 수 있습니다(통제).
  • 자동화 후보를 찾는 명령은 없습니다. 공식 문서에는 사용 기록을 분석해 후보를 뽑아 주는 기능이 없습니다. /insights(최근 세션 요약 HTML 보고서)와 /skill-doctor(스킬별 컨텍스트 비용과 사용 빈도)로 사람이 후보를 고릅니다.

2Skill 만들기
Terminal, ~/workshop/monthly-report 에서
mkdir -p .claude/skills/monthly-report
cat > .claude/skills/monthly-report/SKILL.md <<'WV2EOF'
---
name: monthly-report
description: 월간 소비자보호 점검 보고서를 data 폴더의 CSV와 양식으로 만들고 대조 스크립트를 통과시킨다. 월간 보고서 작성이나 갱신 요청 시 사용한다.
disable-model-invocation: true
allowed-tools: Read Write Edit Bash(python3 *)
---
이번 달 월간 점검 보고서를 만든다. 아래 순서를 지킨다.

1. `data/` 폴더의 지점별 CSV 3개와 `data/prev_month.csv`를 읽는다. 파일이 없거나 열이 다르면 멈추고 사람에게 알린다.
2. `template/월간점검보고서_양식.xlsx`를 `output/월간보고.xlsx`로 복사한다. 제목, 병합 셀, 열 너비, 서식은 바꾸지 않는다.
3. 노란 칸(B4:G7)만 채운다. 합계와 비율은 **Python 코드로 계산**하고 직접 암산하지 않는다. 비율은 소수 첫째 자리까지 사사오입한다.
4. `python3 scripts/reconcile.py output/월간보고.xlsx`를 실행한다. 실패하면 원인을 고쳐 통과할 때까지 반복한다(최대 3회).
5. 통과하면 지점별 요약 표(판매건수, 의심건수, 민원건수, 의심비율, 전월대비)를 한국어로 보고한다. 통과하지 못했으면 완료라고 말하지 말고 실패 내용을 그대로 보고한다.

$ARGUMENTS 가 점검월(예: 2026-10)이다. 양식 A2 셀의 문구를 `점검월: <점검월> / 노란 셀만 입력하세요` 형식으로 바꾸는 것만 허용된다. 점검월이 주어지지 않으면 멈추고 사람에게 묻는다.
WV2EOF

plugin eval은 플러그인의 evals/ 폴더 사례(case.yaml 또는 prompt.md + graders/*.md)를 실행해 점수를 냅니다. 내 권한으로 내 머신에서 실행되므로 신뢰하는 플러그인에만 쓰세요. 사례 작성은 claude plugin eval init의 안내를 따릅니다.

6코드 품질과 일관성 (개발 직군)

에이전트가 만든 코드의 품질을 오래 유지하려면 규칙을 파일과 게이트로 남깁니다: CLAUDE.md의 팀 규칙, .claude/rules/의 경로별 규칙(paths: frontmatter), 훅, 그리고 PR 리뷰 봇. 실습은 트랙 B-2에서 합니다.

한계공식 문서에 확인되는 배포 경로는 저장소에 커밋, 관리형 설정 디렉터리(조직 전체), 플러그인과 마켓 세 가지입니다. 사용 기록에서 후보를 자동으로 뽑는 기능, 레거시 .claude/commands의 Skill 병합 동작은 확인하지 못했습니다.
